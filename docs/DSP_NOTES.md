# DSP の数式と設計根拠

記号: x = 入力サンプル、L = 検出レベル [dB]、T = Threshold [dB]、R = Ratio、W = Knee [dB]、GR = ゲインリダクション量 [dB, ≥0]。

## 1. 信号の流れ(1サンプルごと)
```
入力 -> Input Gain -> [Leveler] -> サイドチェイン(Gain/HPF/LPF/3バンドEQ/重み付け)
     -> ボーカル解析(Plosive/Sibilance の寄与を除去) -> 検出器(Peak/RMS ブレンド)
     -> ゲインコンピューター -> ステレオリンク -> ルックアヘッド -> バリスティクス
     -> ゲイン適用 -> [FET/Vari-Mu の非線形(必要なら OS)] -> DC ブロッカー(非線形時) -> Makeup -> Mix -> Output
```
処理は 3 パス(ゲイン計算 → 非線形/OS → 出力段)で、ブロックサイズに結果が依存しません(1/7/64/333/512 サンプルで比較。差は最大 -144 dB、T13)。

## 2. ゲインコンピューター(対数領域・2次ソフトニー)
o = L − T + W/2 とすると(ニー開始点からの距離)

- o ≤ 0: GR = 0
- 0 < o ≤ W: GR = (1 − 1/R) · o² / (2W)
- o > W: GR = (1 − 1/R) · (o − W/2)

ニー内の2次曲線は、境界で値と傾きが連続になる(o=0 で GR=0 / 傾き0、o=W で傾き 1−1/R)ので、折れ線の継ぎ目で音が変わりません。W=0 は通常のハードニー。**R ≤ 1.0001 では GR = 0**(1:1 は完全に無効)。測定: Ratio 1:1 の出力は入力と bit 単位で一致(T2)。静的カーブの理論値との最大誤差は 0.07 dB 未満(T1、全方式・5 サンプルレート)。

Vari-Mu のみ実効レシオを R_eff = 1 + (R − 1)(1 − e^(−o/12)) として、深く圧縮するほどレシオが上がるようにしています。

## 3. 検出器
- Peak: |x|。RMS: 1次ローパスした x² の平方根 × √2(正弦波ならピーク値と一致するよう校正)。両者を Blend で線形混合。
- RMS 窓はモデルごとに異なります(Transparent 10 / Opto 50 / FET 1 / VCA 5 / Vari-Mu 30 ms)。

## 4. バリスティクス(アタック/リリース)
目標 GR を t[n] として、2 段(デカップルド・スムーズ型)で処理します。

```
gd[n] = max( t[n],  aR·gd[n-1] + (1 − aR)·t[n] )     # リリース(ピークに即座に追従)
gs[n] = aA·gs[n-1] + (1 − aA)·gd[n]                   # アタック(スムージング)
aX    = exp(−1 / (τX · fs))
```
GR(dB)領域で動かすので、アタック/リリース時間は「dB の変化の 63 %」の時間を指します(測定: 20 ms 設定で 20.0 ms、T3)。2 段の構造のため、リリースは設定値よりやや長く出ます(200 ms 設定 → 実測 221 ms の 37 % 点)。**これは仕様です**(アタックのスムージングが重なるため)。

VCA は gd の回復を直線(dB/秒一定)にしています: gd[n] = max(t[n], gd[n−1] − 10/(2.3·τR·fs))。
時定数の更新は 16 サンプルごと(`kCtl`)で、更新間隔内は係数を固定しています。

### Auto Release
GR の速い平均(fast)と遅い平均(slow)から sustain = slow/(fast + 0.05) を作り、τR ← τR × (0.35 + 1.65 · sustain)。短いスパイクの後は速く(×0.35)、長く続いた圧縮の後はゆっくり(×2.0)戻ります。測定: 30 ms バースト後 160 ms / 1.5 s 後 404 ms で戻る(T3)。

## 5. ステレオリンク
GR 領域で、link = 0…1 として GR_c ← GR_c + link · (max(GR_L, GR_R) − GR_c)。測定: 100 %(L=R=15.03 dB)/ 0 %(R=0.00 dB)/ 50 %(中間 7.51 dB)(T9)。

## 6. ルックアヘッドとレイテンシー
目標 GR のスライディング最大値(窓 = Lookahead サンプル + 1)を取り、同じ長さだけ音声を遅らせます。これで「これから来る大きな音のGRが、その音が到着する時点で既に達成されている」状態になります。スライディング最大値は単調 deque で O(1)。総レイテンシー = Lookahead + OS の遅延で、モデルを切り替えても一定に保つため線形モデルにも補償遅延を入れています。

## 7. 非線形ステージ(FET / Vari-Mu)とオーバーサンプリングの必要性
y = ( tanh(k(x + b)) − tanh(kb) ) / ( k · sech²(kb) )
- b > 0 で非対称になり偶数次高調波が出ます。k = k0 + k1 · GR で、深く圧縮するほど歪みが増えます。
- 正規化により小信号ゲインは 1(圧縮していない時に音量が変わらない)。
- tanh は無限に高次の倍音を作るので、標準サンプルレートでは折り返し(エイリアス)が出ます。そこで 2x / 4x(juce::dsp::Oversampling、ポリフェーズ IIR ハーフバンド)の内側でのみ適用。**GR の計算は OS の外**(帯域制限されているため不要)にして CPU を節約します。
- 測定(T4b): 44.1 kHz で非調波成分 1x -102 dB → 2x -133 dB。4x は 2x とほぼ同じ。→ 2x を推奨。
- IIR 半帯域フィルターは線形位相ではありません(FET OS で 20 Hz の位相 +8.5° は DC ブロッカーによる)。

## 8. ボーカル機能の数式
- **検出信号の合成**: x' = x + amtP · pState · (HP180Hz(x) − x) + amtS · sState · (LP4kHz(x) − x)。pState / sState は 0〜1 の制御値で、1 のとき低域(または高域)の寄与が検出から取り除かれます。
- **Plosive**: 低域(150 Hz 以下)の比 ratioLow = eLow/eTot > 0.6 かつ 速い/遅い包絡の比 burst = eFast/eSlow > 1.6 のとき 40 ms ホールドして pState = 1。
- **Sibilance**: 高域(4 kHz 以上)の比 ratioHigh = eHigh/eTot を smoothstep(0.35, 0.60) で 0〜1 にして sState とする。
- **Syllable**: 立ち上がり(burst > 1.8)で attack × (1 + 0.8·amt)、音節の谷(eSyl < 0.35·ePhr)で release × (1 − 0.7·amt)。
- **Phrase**: 活動度 pAct(Threshold の 15 dB 下を境に 0/1 を平滑)。release × (1 + amt·(0.5·pAct − 0.5·(1 − pAct)))。
- **Adaptive**: threshold −= amt · clamp(0.5 · (phraseDb − refDb), ±6 dB) · pAct、ratio × (1 + 0.3 · amt · clamp((crest − 12 dB)/12, ±1))。
- **Leveler**: 250 ms RMS から目標との差(±12 dB に制限)× amt を、上げ 0.8 s / 下げ 0.3 s の1次系で追う。-55 dB 以下では動かさない。

> これらは経験則(ヒューリスティック)で、数値は合成信号での調整です。実際の歌声に最適化されたものではありません。

## 9. 安全性
- 入力の NaN / Inf は 0 に置換、内部は double、出力は ±1e4 にクランプ(T14: ランダム入力・ランダム設定で 13,500 ブロック、非有限値 0)。
- DC ブロッカー(非線形モデル時)、`juce::ScopedNoDenormals`、無音入力で出力が厳密に 0(T5)。
- パラメーター(Input/Output/Makeup/Mix/Threshold/Ratio/Knee/Bypass)は 10〜20 ms のスムージング。急変時のサンプル間段差は正弦波の傾き以下(T13)。
- `process()` / `setParams()` 内の `operator new` は 0 回(T14)。ファイル I/O はプリセット操作(メッセージスレッド)だけ。
